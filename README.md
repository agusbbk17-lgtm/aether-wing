Aether Wing is a 3D, HD, richly textured procedural flight game built with Three.js (WebGL2). Pilot a responsive aircraft through island ring courses, search and rescue sorties, and timed trials with realistic flight physics (pitch, roll, yaw, throttle, stall warnings, and flap mechanics). Features PBR-style procedural aircraft texturing (panel lines, rivets, wear), multi-layered splat-blended island terrain, animated water with reflections, volumetric cloudscapes, chase/cockpit cameras, full cockpit HUD instruments, and dynamic WebAudio sound synthesis.

## Run it

```sh
node serve.ts
```
